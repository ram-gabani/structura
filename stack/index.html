What is a Stack?

In an array, you can access any slot freely at random. In contrast, a Stack is a disciplined linear data structure where all insertions and deletions are restricted to one single end, universally known as the TOP of the stack.

Because new items are piled directly on top of older ones, the most recently added item is always the first one to be removed. This behavioral rule is formalized as LIFO: Last In, First Out.

LIFO Principle
Last In, First Out
The newest item placed on the stack must be removed before any older items beneath it can be accessed.
Single Pointer
TOP Index
All state is tracked by an integer index top. When empty, top = -1. Increments on push, decrements on pop.
⚡ O(1) Speed
Instant Operations
Pushing, popping, and peeking take strictly constant time because operations occur only at the top index.
Boundary Guard
Overflow / Underflow
Pushing to a full stack triggers Overflow; popping from an empty stack triggers Underflow.

💡 Why TOP Starts at -1

Because C arrays use 0-based indexing (Slot 0 is the first valid physical element), a top value of 0 means the stack contains one element sitting at arr[0]. Therefore, when the stack has zero elements (empty), top must be set to -1!

Everyday Analogies: LIFO in the Real World

Real-life mechanisms operating on the exact same physical rules

🍽️ Kitchen / Buffet
Stack of Clean Plates
At a university dining hall, clean plates are washed and stacked on top. The next student picks the topmost plate (the last one placed). Accessing the bottom plate requires removing all plates above it.
🎾 Sport Canister
Tennis Ball Canister
A vertical tube with a sealed bottom and one open top. Ball #1 goes to the bottom. Ball #3 sits at the mouth. You cannot take Ball #1 out without first removing Balls #3 and #2.
🌐 Browser History
Browser Back Button
Every web page you visit is pushed onto your navigation stack. Clicking the 'Back' button pops the most recent page, returning you to the page visited immediately prior.

Array-Based vs. Linked List Stack

Comparing the two implementation techniques in standard C

Implementation Styles
Evaluation Criteria Array Implementation Linked List Implementation
Memory Allocation Fixed, contiguous block declared at compile time (e.g. int arr[MAX];) Dynamic heap allocation per element (malloc per push)
Capacity Limit Fixed maximum size (prone to Stack Overflow if capacity reached) Unlimited (limited only by available system RAM)
Memory Overhead Zero extra pointers. Compact contiguous RAM. Extra pointer (struct Node *next) per node (+8 bytes).
Push / Pop Speed ⚡ O(1) Instant Math ⚡ O(1) Pointer Rewire
Simplicity Extremely simple: integer index increment and decrement. Requires careful pointer updates and free() on pop.
