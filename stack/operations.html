Stack Operations: Push, Pop, Peek & Status

Every stack operation executes in strictly \(O(1)\) constant time because all mutations happen at the single memory offset tracked by the top index. Explore clean, compilable C implementations with safety boundary guards.

1. The Push Operation (Insertion)

Adding an element onto the top of the stack

⚡ O(1) Time
Algorithmic Steps:
  1. Overflow Check: Check if top == MAX - 1. If true, the stack is full; display an error message and abort.
  2. Increment: Advance the top pointer: top = top + 1.
  3. Store: Place the new element at the newly incremented index: arr[top] = value.
C Push Function 
void push(struct Stack *s, int value) {
    /* 1. Check for Stack Overflow */
    if (s->top == MAX - 1) {
        printf("Error: Stack Overflow! Cannot push %d.\n", value);
        return;
    }
    /* 2. Increment top and store value */
    s->top++;
    s->arr[s->top] = value;
    printf("Pushed %d onto stack (top = %d).\n", value, s->top);
}

2. The Pop Operation (Deletion)

Extracting and removing the topmost element

⚡ O(1) Time
Algorithmic Steps:
  1. Underflow Check: Check if top == -1. If true, the stack contains zero elements; display error and abort.
  2. Retrieve: Copy the element sitting at arr[top].
  3. Decrement: Move the top pointer down: top = top - 1.
  4. Return: Return the retrieved value.
C Pop Function 
int pop(struct Stack *s) {
    /* 1. Check for Stack Underflow */
    if (s->top == -1) {
        printf("Error: Stack Underflow! Stack is empty.\n");
        return -1; /* Sentinel error value */
    }
    /* 2. Retrieve top item and decrement pointer */
    int poppedVal = s->arr[s->top];
    s->top--;
    return poppedVal;
}

3. Peek, isEmpty & isFull

Inspection utilities that do not modify stack contents

Inspect Top
peek() / top()
Returns arr[top] without decrementing top. Stack size remains unchanged. 
int peek(struct Stack *s) {
    if (s->top == -1) return -1;
    return s->arr[s->top];
}
Empty Guard
isEmpty()
Returns 1 (true) if top == -1; returns 0 otherwise. 
int isEmpty(struct Stack *s) {
    return (s->top == -1);
}
Capacity Guard
isFull()
Returns 1 (true) if top == MAX - 1; returns 0 otherwise. 
int isFull(struct Stack *s) {
    return (s->top == MAX - 1);
}

Complete Compilable C Program

Self-contained C99 code encapsulating struct Stack and all operations

C99 stack_implementation.c 
#include <stdio.h>
#include <stdlib.h>

#define MAX 5   /* Fixed maximum stack capacity */

/* Stack Structure Definition */
struct Stack {
    int arr[MAX];
    int top;
};

/* Initialize Stack */
void initStack(struct Stack *s) {
    s->top = -1;
}

/* Push an item onto stack */
void push(struct Stack *s, int val) {
    if (s->top == MAX - 1) {
        printf("Stack Overflow! Cannot push %d.\n", val);
        return;
    }
    s->arr[++(s->top)] = val;
    printf("Pushed: %d\n", val);
}

/* Pop the top item */
int pop(struct Stack *s) {
    if (s->top == -1) {
        printf("Stack Underflow! Stack is empty.\n");
        return -1;
    }
    return s->arr[(s->top)--];
}

/* Peek top element */
int peek(struct Stack *s) {
    if (s->top == -1) {
        printf("Stack is empty.\n");
        return -1;
    }
    return s->arr[s->top];
}

/* Display Stack contents from TOP down to BASE */
void display(struct Stack *s) {
    if (s->top == -1) {
        printf("Stack is empty.\n");
        return;
    }
    printf("STACK (TOP to BOTTOM): ");
    for (int i = s->top; i >= 0; i--) {
        printf("[%d] ", s->arr[i]);
    }
    printf("\n");
}

int main(void) {
    struct Stack myStack;
    initStack(&myStack);

    push(&myStack, 10);
    push(&myStack, 25);
    push(&myStack, 40);
    display(&myStack);

    printf("Peek Top: %d\n", peek(&myStack));

    printf("Popped: %d\n", pop(&myStack));
    display(&myStack);

    return 0;
}

Pushed: 25
Pushed: 40
STACK (TOP to BOTTOM): [40] [25] [10] 
Peek Top: 40
Popped: 40
STACK (TOP to BOTTOM): [25] [10]
