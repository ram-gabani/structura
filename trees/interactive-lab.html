Five Binary Tree Types: Technical Comparison Reference

Exhaustive classification criteria tested in university data structure semester papers

Curriculum Core
Tree Type Structural Rule Leaf Requirement Typical Height Key Identification Test
Full Binary Tree
(Strict / Proper)		 Every node has either 0 or exactly 2 children. No node can have 1 child. Leaves may appear at different levels. Leaves do not require uniform depth. log2(N+1) - 1 ≤ h ≤ (N-1)/2 Scan for any node with degree == 1. If none exists, it is Full.
Complete Binary Tree All levels are fully filled except possibly the last level, which fills strictly from left to right without gaps. Leaves reside only on the last two levels (h - 1 and h); bottom leaves are left-aligned. h = ⌊log2 N⌋ (Guaranteed compact depth) Level-order traversal: once a NULL child is encountered, no subsequent non-NULL node may follow.
Perfect Binary Tree Every internal node has exactly 2 children, AND all levels are 100% full. All leaves must reside at the exact same depth/level. h = log2(N+1) - 1
Nodes = 2h+1 - 1		 Verify both that the tree is Full AND all leaves have identical depth.
Balanced Binary Tree
(Height-Balanced)		 For every node, the height difference between left and right subtrees is at most 1: |BF| ≤ 1. Leaves need not share a level; height variance is constrained across branches. O(log N)
h ≤ 1.44 log2 N (AVL)		 Calculate balance factor BF = h(Left) - h(Right) at every node. All BF values must lie in {-1, 0, 1}.
Degenerate / Skewed
(Left / Right Skewed)		 Every internal node has exactly one child. Behavers structurally like a Singly Linked List. Exactly one single leaf exists at the very terminus of the chain. h = N - 1
Worst-case linear height		 Verify every non-leaf node has degree == 1. All edges branch in one continuous linear chain.

C Implementation Connection: Property Verification Functions

Textbook C algorithms for identifying and verifying each binary tree type

C Function: Full Binary Tree Validation 
#include <stdbool.h>
#include <stdlib.h>

struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
};

/* Checks if every node has either 0 or 2 children */
bool isFullTree(struct TreeNode* root) {
    /* Base case: an empty tree is full by definition */
    if (root == NULL)
        return true;

    /* If leaf node (degree 0): valid! */
    if (root->left == NULL && root->right == NULL)
        return true;

    /* If both children exist (degree 2): recursively check both subtrees */
    if (root->left != NULL && root->right != NULL)
        return isFullTree(root->left) && isFullTree(root->right);

    /* If exactly one child exists (degree 1): Full property is violated! */
    return false;
}
C Function: Complete Binary Tree Validation (Level-Order Queue) 
#include <stdbool.h>
#include <stdlib.h>
#define MAX_QUEUE 1000

struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
};

/* Checks level-order contiguousness: once a NULL is seen, no node may follow */
bool isCompleteTree(struct TreeNode* root) {
    if (root == NULL) return true;

    struct TreeNode* queue[MAX_QUEUE];
    int front = 0, rear = 0;
    bool seenNull = false;

    queue[rear++] = root;
    while (front < rear) {
        struct TreeNode* curr = queue[front++];

        if (curr == NULL) {
            /* First gap detected */
            seenNull = true;
        } else {
            /* If a valid node appears after an empty gap, tree is NOT complete */
            if (seenNull) return false;

            /* Push both child pointers (even if NULL) into the queue */
            queue[rear++] = curr->left;
            queue[rear++] = curr->right;
        }
    }
    return true;
}
C Function: Perfect Binary Tree Validation 
#include <stdbool.h>
#include <stdlib.h>

struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
};

/* Helper: Finds the depth of the leftmost leaf */
int findLeftmostDepth(struct TreeNode* node) {
    int d = 0;
    while (node != NULL) {
        d++;
        node = node->left;
    }
    return d;
}

/* Recursive check: All leaves at depth d, all internal nodes have degree 2 */
bool isPerfectRec(struct TreeNode* root, int d, int level) {
    if (root == NULL) return true;

    /* Leaf node check: must equal the leftmost depth */
    if (root->left == NULL && root->right == NULL)
        return (d == level + 1);

    /* Internal node must have exactly 2 children */
    if (root->left == NULL || root->right == NULL)
        return false;

    return isPerfectRec(root->left, d, level + 1) &&
           isPerfectRec(root->right, d, level + 1);
}

bool isPerfect(struct TreeNode* root) {
    int d = findLeftmostDepth(root);
    return isPerfectRec(root, d, 0);
}
C Function: Height-Balanced Validation 
#include <stdbool.h>
#include <stdlib.h>

struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
};

/* Checks if tree is height-balanced in O(N) single-pass post-order */
bool isBalancedHelper(struct TreeNode* root, int* height) {
    if (root == NULL) {
        *height = 0;
        return true;
    }

    int leftHeight = 0, rightHeight = 0;
    bool leftBal = isBalancedHelper(root->left, &leftHeight);
    bool rightBal = isBalancedHelper(root->right, &rightHeight);

    *height = 1 + (leftHeight > rightHeight ? leftHeight : rightHeight);

    /* Balance Factor = height(left) - height(right) */
    int bf = leftHeight - rightHeight;
    if (bf < -1 || bf > 1)
        return false;

    return leftBal && rightBal;
}

bool isBalanced(struct TreeNode* root) {
    int height = 0;
    return isBalancedHelper(root, &height);
}
C Function: Degenerate / Skewed Tree Validation 
#include <stdbool.h>
#include <stdlib.h>

struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
};

/* Checks that every internal node has strictly one child */
bool isDegenerate(struct TreeNode* root) {
    if (root == NULL) return true;

    /* Terminal leaf node: valid end of chain */
    if (root->left == NULL && root->right == NULL)
        return true;

    /* Internal node branching into 2 children: NOT degenerate! */
    if (root->left != NULL && root->right != NULL)
        return false;

    /* Recurse down the single active child link */
    if (root->left != NULL)
        return isDegenerate(root->left);
    else
        return isDegenerate(root->right);
}
