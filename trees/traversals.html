Binary Tree Traversals

Unlike linear arrays traversed by a single index counter from 0 to n-1, visiting every node in a branching tree requires a structured recursive strategy. Master In-order, Pre-order, Post-order, and Breadth-First Level-Order traversals.

Reference Tree Model

We will trace all four traversal orders against this exact 5-node tree

1
2
3
4
5
In-Order (L-Root-R)
4 → 2 → 5 → 1 → 3
Traverse left subtree, visit root, traverse right subtree. In a BST, produces sorted order!
Pre-Order (Root-L-R)
1 → 2 → 4 → 5 → 3
Visit root first, then left subtree, then right subtree. Used to clone or serialize trees.
Post-Order (L-R-Root)
4 → 5 → 2 → 3 → 1
Traverse subtrees first, visit root last. Used to delete trees and evaluate expression trees.

C Implementation: The 3 Classic Traversal Functions

Notice how just swapping the order of lines changes the entire traversal!

Elegant Recursion
C99 traversals.c 
/* 1. In-Order Traversal: Left -> Root -> Right */
void inOrder(struct TreeNode *root) {
    if (root == NULL) return;
    inOrder(root->left);           /* 1. Left Subtree */
    printf("%d ", root->data);     /* 2. Process Root */
    inOrder(root->right);          /* 3. Right Subtree */
}

/* 2. Pre-Order Traversal: Root -> Left -> Right */
void preOrder(struct TreeNode *root) {
    if (root == NULL) return;
    printf("%d ", root->data);     /* 1. Process Root */
    preOrder(root->left);          /* 2. Left Subtree */
    preOrder(root->right);         /* 3. Right Subtree */
}

/* 3. Post-Order Traversal: Left -> Right -> Root */
void postOrder(struct TreeNode *root) {
    if (root == NULL) return;
    postOrder(root->left);         /* 1. Left Subtree */
    postOrder(root->right);        /* 2. Right Subtree */
    printf("%d ", root->data);     /* 3. Process Root */
}
💡 Time & Space Complexity Analysis
  • Time Complexity: \(O(n)\) — Every single node in the tree is visited exactly once.
  • Space Complexity: \(O(h)\) — Memory used by the recursive Call Stack equals the tree height \(h\). In a balanced tree, \(h = O(\log n)\); in a skewed degenerate tree, \(h = O(n)\).

Breadth-First / Level-Order Traversal

Visiting nodes level-by-level from top to bottom using a FIFO Queue

Queue Driven

In Breadth-First traversal, nodes are printed horizontally across Level 0, then Level 1, then Level 2. Because subtrees branch out, recursion cannot directly accomplish this; we use a FIFO Queue!

1. Enqueue Root [1] → Queue: [1]
2. Dequeue 1, print 1. Enqueue its children (2, 3) → Queue: [2, 3]
3. Dequeue 2, print 2. Enqueue its children (4, 5) → Queue: [3, 4, 5]
4. Dequeue 3, print 3. It has no children → Queue: [4, 5]
5. Dequeue 4 & 5, print both. Queue is empty → Finished!
Output Order: 1 → 2 → 3 → 4 → 5
