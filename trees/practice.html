Problem 01

Calculate the Maximum Height / Depth of a Binary Tree

O(n) Time

Write a recursive C function int maxDepth(struct TreeNode *root) that returns the number of nodes along the longest path from the root node down to the farthest leaf node.

Hint: If root is NULL, depth is 0. Otherwise, recursively compute maxDepth(root->left) and maxDepth(root->right). The answer is 1 + max(leftDepth, rightDepth).
View Complete C Solution ↓ 
#include <stdio.h>
#include <stdlib.h>

struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
};

// Recursive function to calculate maximum depth
int maxDepth(struct TreeNode* root) {
    if (root == NULL) {
        return 0; // Empty tree has depth 0
    }
    int leftH = maxDepth(root->left);
    int rightH = maxDepth(root->right);
    return 1 + (leftH > rightH ? leftH : rightH);
}
Problem 02

Validate if a Binary Tree is a Valid BST

O(n) Time

Write a recursive C function that verifies whether every node in the binary tree satisfies the BST property: every node in the left subtree is strictly less, and every node in the right subtree is strictly greater.

Hint: Merely checking root->val > root->left->val is insufficient! A node in the left subtree could violate an ancestor's bound. Pass allowable minimum and maximum range limits: validate(root, min, max).
View Complete C Solution ↓ 
#include <limits.h>
#include <stdbool.h>

bool isBSTUtil(struct TreeNode* node, long minVal, long maxVal) {
    if (node == NULL) return true;
    
    // Check if current node violates upper/lower bounds
    if (node->val <= minVal || node->val >= maxVal) {
        return false;
    }
    
    // Left child must be < node->val, right child must be > node->val
    return isBSTUtil(node->left, minVal, node->val) &&
           isBSTUtil(node->right, node->val, maxVal);
}

bool isValidBST(struct TreeNode* root) {
    return isBSTUtil(root, LONG_MIN, LONG_MAX);
}
Problem 03

Find the Minimum Value Node (In-Order Successor Helper)

O(h) Time

Write a concise C function that locates the node with the minimum key in a non-empty BST, essential for 2-child BST deletion.

Hint: In any BST, smaller values always reside strictly in left subtrees. Keep following curr->left until it reaches NULL!
View Complete C Solution ↓ 
struct TreeNode* findMin(struct TreeNode* root) {
    if (root == NULL) return NULL;
    struct TreeNode* curr = root;
    // Walk down to the leftmost leaf
    while (curr->left != NULL) {
        curr = curr->left;
    }
    return curr;
}

2. Common Tree Implementation Pitfalls in C

Avoid these bugs frequently flagged in university practicals

Pitfall 01
Degenerate / Skewed BST
Inserting keys already in sorted order (e.g. 10, 20, 30, 40) creates a straight line resembling a linked list. Search complexity degrades from O(log n) to O(n)!
Pitfall 02
Forgetting to Return Node
In recursive BST insertion: root->left = insert(root->left, val);. If you forget to assign the return value back to root->left, new nodes are never connected!
Pitfall 03
Preorder Tree Deletion Leak
Calling free(root) before deleting children leaves orphaned heap subtrees! Always use Postorder traversal to free left and right children before freeing the parent node.
