What is a Tree?

Arrays, Linked Lists, Stacks, and Queues are all linear data structures: elements follow a single straight sequence. In contrast, a Tree is a non-linear hierarchical data structure composed of nodes connected by directed edges, radiating from a single top node called the ROOT.

Trees reflect real-world relationships: file system directory folders, corporate organizational charts, HTML DOM document trees, and decision logic.

Single Root
Ancestor Node
The topmost apex of the tree with zero incoming parent edges. Every node descends from Root.
Parent-Child
Directed Branching
Every child node has exactly ONE parent. Nodes sharing the same parent are Siblings.

Nodes with zero children (both left and right pointer fields point to NULL).

Tree Terminology: Exam Definitions Cheat Sheet

Core vocabulary and fundamental tree definitions

Syllabus Core
Cyan • Root
Purple • Internal Node
Green • Leaf Node
Line • Edge
1. Root:

The topmost ancestral apex node with zero incoming parent edges (Node A). Every tree possesses exactly one root.

2. Edge:

The directed link connecting a parent node to a child node. A tree with \(N\) nodes always contains exactly \(N - 1\) edges.

3. Parent:

An immediate predecessor node directly connected to lower successor nodes (e.g., A is the parent of B and C).

4. Child:

An immediate successor node directly descended from an upper parent (e.g., D and E are children of B).

5. Sibling:

Nodes that share the exact same immediate parent node (e.g., B and C share parent A; D and E share parent B).

6. Leaf Node (Terminal):

A bottom node possessing zero children (Degree = 0). Nodes D, E, and F are leaves whose left and right pointers are NULL.

7. Internal Node (Non-Leaf):

Any node with at least one child (Degree ≥ 1). Nodes B and C are internal nodes connecting the root to the leaves.

8. Degree of a Node:

The number of children directly attached to a node. Node B has Degree 2, Node C has Degree 1, and leaves have Degree 0.

9. Level:

Hierarchical tier from top to bottom. Root is at Level 0, its children at Level 1, and grandchildren at Level 2.

10. Depth of a Node:

The length of the unique path (number of edges) from the Root down to that specific node. Depth(D) = 2.

11. Height of a Node & Tree:

Length of longest path from that node down to a leaf. Height of a tree equals the height of its Root (Height = 2 edges).

12. Subtree:

Any node in the tree along with all of its descendants, forming a valid tree itself (e.g., node B with leaves D and E).

The Five Types of Binary Trees

A binary tree restricts each node to at most 2 children: Left and Right

Strict / Proper
1. Full Binary Tree
Every node has either 0 or exactly 2 children. No node possesses only 1 child!
Heap Foundation
2. Complete Binary Tree
All levels are completely filled except possibly the last level, which must be filled strictly from left to right.
Symmetric Apex
3. Perfect Binary Tree
All interior nodes have 2 children, and every leaf node sits at the exact same depth level. Total nodes = \(2^{h+1} - 1\).
AVL Standard
4. Balanced Binary Tree
For every node, the height difference between left and right subtrees is at most 1 (\(|h_L - h_R| \le 1\)).
Worst Case
5. Degenerate / Skewed Tree
Every parent node has only 1 child. The tree structure collapses into a linear linked list with \(O(n)\) lookup time.

Linked Representation in Standard C

Declaring the TreeNode struct with left and right pointer fields

C TreeNode Struct Definition 
#include <stdio.h>
#include <stdlib.h>

/* Binary Tree Node Structure */
struct TreeNode {
    int data;                    /* Data payload */
    struct TreeNode *left;       /* Left child memory address */
    struct TreeNode *right;      /* Right child memory address */
};

/* Helper constructor to allocate a new node */
struct TreeNode* createTreeNode(int val) {
    struct TreeNode *newNode = (struct TreeNode*)malloc(sizeof(struct TreeNode));
    newNode->data = val;
    newNode->left = NULL;
    newNode->right = NULL;
    return newNode;
}
