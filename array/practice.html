Problem 1: Reverse an Array in Place
Easy

Story: A train has reached the end of the line and needs to reverse its compartments completely so the first carriage becomes the last, and the last becomes the first.

Input: [10, 20, 30, 40, 50]
Output: [50, 40, 30, 20, 10]
Hint: Use two pointers: one at the start (left = 0) and one at the end (right = n - 1). Swap their values, then move left++ and right-- until they meet in the middle!
▶ View Step-by-Step C Solution 
#include <stdio.h>

void reverseArray(int arr[], int n) {
    int left = 0;
    int right = n - 1;

    while (left < right) {
        int temp = arr[left];
        arr[left] = arr[right];
        arr[right] = temp;

        left++;
        right--;
    }
}
Line 4-5: Dual Pointers
Boundary Pointers
Initialize left = 0 and right = n - 1 at opposing array ends.
Line 7-13: In-Place Swap
Convergence Loop
Swap values using a temporary variable, incrementing left and decrementing right until they meet.
Problem 2: Find Maximum & Minimum Value
Easy

Story: A teacher needs to identify the highest test score and the lowest test score in a classroom of students stored in an array.

Input: [45, 92, 18, 77, 85, 33]
Output: Max = 92, Min = 18
Hint: Start by assuming the first item arr[0] is both the max and min. Then loop through the rest of the slots from index 1 to the end, updating max if a bigger item is found, and min if a smaller item is found.
▶ View Step-by-Step C Solution 
void findMaxMin(int arr[], int n, int *maxVal, int *minVal) {
    *maxVal = arr[0];
    *minVal = arr[0];

    for (int i = 1; i < n; i++) {
        if (arr[i] > *maxVal) *maxVal = arr[i];
        if (arr[i] < *minVal) *minVal = arr[i];
    }
}
Line 2-3: Baseline Seed
Initial Guess
Seed *maxVal and *minVal with the first element arr[0].
Line 5-8: Single Scan
Linear Traversal
Traverse remaining elements from index 1 to n - 1, updating bounds in O(n) time.
Problem 3: Move All Zeroes to the End
Medium

Story: A train conductor wants to move all empty seats (represented by 0) to the very back of the train while keeping all seated passengers in their relative forward order.

Input: [0, 1, 0, 3, 12]
Output: [1, 3, 12, 0, 0]
Hint: Keep a writeIndex = 0. Loop through the array; whenever you find a non-zero number, write it to arr[writeIndex++]. At the end, fill remaining slots up to n with zeroes!
▶ View Step-by-Step C Solution 
void moveZeroes(int arr[], int n) {
    int writeIndex = 0;

    // 1. Move non-zero elements forward
    for (int i = 0; i < n; i++) {
        if (arr[i] != 0) {
            arr[writeIndex++] = arr[i];
        }
    }

    // 2. Fill the remaining spots with zeroes
    while (writeIndex < n) {
        arr[writeIndex++] = 0;
    }
}
Line 2: Write Pointer
Compaction Index
Track the next available forward position using writeIndex.
Line 5-13: Tail Zeroing
Two-Pass In-Place
Non-zero numbers preserve relative order; tail slots are filled with 0.

2. Common Pitfalls & Bugs in C

The 3 most common beginner mistakes and how to avoid them

Pitfall 01 ⚠️
Out of Bounds Access
An array of size 5 only has indices 0 to 4. Accessing arr[5] triggers an illegal memory access!
❌ arr[5] = 100; // Crash!
✓ arr[4] = 100; // Valid (n-1)
Pitfall 02 ⚠️
Off-by-One Loop Error
Using <= n instead of < n in a loop condition will execute 1 extra round and read out of bounds on the final turn.
❌ for(int i=0; i<=n; i++)
✓ for(int i=0; i<n; i++)
Pitfall 03 ⚠️
Uninitialized Memory
In C, declaring an array without setting values leaves whatever random garbage numbers happened to be in that RAM location.
❌ int arr[5]; // Garbage
✓ int arr[5] = {0}; // Zeroed
