Putting Chaos in Order: Sorting Algorithms

A Sorting Algorithm rearranges a list of elements into ascending (smallest to largest) or descending order based on a comparison operator. In this guide, we break down Bubble Sort, Selection Sort, Insertion Sort, and Radix Sort with intuitive real-world metaphors and step-by-step traces.

Bubble Sort
Neighbor Swaps
Repeatedly compares and swaps adjacent pairs, bubbling maximums to the right.
Selection Sort
Minimum Picker
Scans for the champion minimum and places it first; performs at most n-1 swaps.
Insertion Sort
Card Slide
Slides items into a sorted hand; achieves lightning-fast O(n) on nearly-sorted data.
Radix Sort
Bucket Sorter
Non-comparative digit-by-digit bucketing with linear-proportional O(n × k) time.

1. Bubble Sort: "Bubbling the Largest to the End"

Repeatedly comparing and swapping adjacent neighbor elements

🔄 Neighbor Swap

🫧 Real-Life Metaphor:

Imagine air bubbles rising in water. The largest bubbles float upward to the surface fastest. Similarly, in Bubble Sort, adjacent elements are compared and swapped if out of order, bubbling the largest value to the end in each pass!

When to use:

When simplicity and short code are preferred, or for educational demonstrations.

Bubble Sort Pass 1: [5, 1, 4, 2]
1
Compare (5, 1) → Swap!
5 > 1. Swap them! Array: [1, 5, 4, 2]
2
Compare (5, 4) → Swap!
5 > 4. Swap them! Array: [1, 4, 5, 2]
3
Compare (5, 2) → Swap!
5 > 2. Swap! End of Pass 1: [1, 4, 2, 5 (Locked)]
Time Complexity
Best: O(n) • Worst: O(n²)
Early break flag enables linear time on sorted input. Worst case requires full comparisons across passes.
Space Complexity
O(1) Auxiliary Space
Performs completely in-place sorting with zero auxiliary dynamic memory allocations.
Stability
Stable Algorithm
Preserves the relative order of duplicate values since only strictly greater items are swapped.

2. Selection Sort: "Finding the Champion Minimum"

Scanning for the minimum element and placing it at the front

🏆 Minimum Picker

🛒 Real-Life Metaphor:

Imagine picking fruits in a store: you scan the entire basket for the cheapest fruit and put it first in your basket. Then you scan the rest for the next cheapest and place it second.

When to use:

When write memory writes are expensive (e.g. EEPROM / Flash memory) because Selection Sort makes at most O(n) swaps.

Selection Sort: [20, 12, 10, 15, 2]
1
Round 1: Find Smallest in Entire Array
Minimum is 2. Swap with index 0 (20). Array: [2, 12, 10, 15, 20]
2
Round 2: Find Smallest in [12, 10, 15, 20]
Minimum is 10. Swap with 12. Array: [2, 10, 12, 15, 20]
Time Complexity
O(n²) in All Cases
Best, Worst, and Average cases are all O(n²) since it always scans the remaining unsorted subarray.
Minimal Swaps
Max n-1 Swaps
Performs at most n - 1 swaps total, making it ideal for devices where write operations are costly.
Stability
Unstable by Default
Long-distance swaps can alter the original relative positions of duplicate equal elements.

3. Insertion Sort: "Sorting Playing Cards in Hand"

How human card players naturally organize their hand

🃏 Card Slide

🃏 Real-Life Metaphor:

When dealt cards in a game, you keep your sorted cards in hand. Each time a new card arrives, you slide it backward until it fits in its exact sorted slot!

⚡ Superpower:

If data is already mostly sorted, Insertion Sort runs in lightning-fast O(n) linear time.

Inserting 3 into Hand [1, 4, 7]
1
Extract Key = 3. Compare with 7
7 > 3 → Slide 7 right. Hand: [1, 4, _, 7]
2
Compare with 4
4 > 3 → Slide 4 right. Hand: [1, _, 4, 7]
3
Compare with 1 → Insert!
1 < 3 → Drop 3 into empty slot! Hand: [1, 3, 4, 7]
Adaptive Speed
Best: O(n) • Worst: O(n²)
Requires only 1 comparison per element when input is already sorted or nearly sorted.
Stability
Stable In-Place
Maintains original relative order of equal items and operates with O(1) space.
Online Processing
Stream Friendly
Can sort a list as it receives new elements in real-time without needing the whole array upfront.

4. Radix Sort: "Digit-by-Digit Bucket Sorter"

Non-comparative sorting using Least Significant Digit (LSD) to Most Significant Digit (MSD)

⚡ O(n × k) Non-Comparative

Unlike Bubble or Selection Sort which compare two elements at a time, Radix Sort is a non-comparative algorithm. It sorts numbers digit by digit starting from the Least Significant Digit (Units digit → Tens digit → Hundreds digit) using 10 buckets (0 to 9).

Worked Example: Sorting [170, 45, 75, 90, 802, 24, 2, 66]
Step 1: Sort by Units Digit (LSD):
170(0), 90(0), 802(2), 2(2), 24(4), 45(5), 75(5), 66(6)
→ List: [170, 90, 802, 2, 24, 45, 75, 66]
Step 2: Sort by Tens Digit:
802(0), 2(0), 24(2), 45(4), 66(6), 170(7), 75(7), 90(9)
→ List: [802, 2, 24, 45, 66, 170, 75, 90]
Step 3: Sort by Hundreds Digit (MSD):
2(0), 24(0), 45(0), 66(0), 75(0), 90(0), 170(1), 802(8)
→ Final Sorted Output: [2, 24, 45, 66, 75, 90, 170, 802]
Linear-Bound Time
Time: O(n × k)
Runs in linear-proportional time where k is the digit count of the largest number.
Non-Comparative
No Comparisons
Bypasses the theoretical O(n log n) comparison limit by utilizing positional digit buckets.
Subroutine
Stable Sub-Sort
Employs stable counting sort internally per digit position to retain previous digit hierarchy.

Clean C Implementation: Bubble Sort

Beginner-friendly C function with early-exit optimization

📄 bubble_sort.c 
#include <stdio.h>

void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0; // Track if any swaps occurred

        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                // Swap neighbor pairs
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = 1;
            }
        }
        // If no swaps occurred, the list is already sorted!
        if (swapped == 0) break;
    }
}

int main() {
    int data[] = {64, 34, 25, 12, 22, 11, 90};
    int n = sizeof(data) / sizeof(data[0]);

    bubbleSort(data, n);

    printf("Sorted Array:\n");
    for (int i = 0; i < n; i++) {
        printf("%d ", data[i]);
    }
    printf("\n");
    return 0;
}
👨‍🏫 Code Highlights
Line 7: j < n - i - 1
Shrinking Inner Boundary
Because the largest elements are already locked at the back in earlier passes, we avoid re-checking them!
Line 17: Early Break Flag
Adaptive Early Exit
If an entire pass completes without a single swap, the computer terminates early in O(n) time.
