# Structura

Interactive visual learning platform for Data Structures in C.

## Topics

- Arrays
- Linked Lists
- Stacks
- Queues
- Trees
- Graphs

## Features

- Beginner-friendly C explanations
- Interactive data-structure visualizers
- Algorithm walkthroughs
- Complexity explanations
- Practice questions and quizzes
- Dark and light themes
- Responsive design

## Run Locally

Start a local server from the project folder:

```bash
python -m http.server 8080
```

Then open:

```text
http://localhost:8080/
```
