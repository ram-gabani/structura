Challenge 1: Reverse a Singly Linked List In-Place

Classic Exam Problem

Given the HEAD of a singly linked list, reverse the direction of all next pointers in-place using O(1) extra auxiliary memory.

💡 Reveal 3-Pointer Algorithm & C Solution

Strategy: Use three pointers: prev = NULL, curr = head, and next = NULL. In each step, preserve next = curr->next, redirect curr->next = prev, slide prev = curr, and slide curr = next. 

struct Node* reverseList(struct Node *head) {
    struct Node *prev = NULL;
    struct Node *curr = head;
    struct Node *next = NULL;

    while (curr != NULL) {
        next = curr->next;  /* 1. Store next node */
        curr->next = prev;  /* 2. Reverse current node's pointer */
        prev = curr;        /* 3. Advance prev one step */
        curr = next;        /* 4. Advance curr one step */
    }

    return prev; /* prev is the new HEAD! */
}

Challenge 2: Find the Middle Node in One Pass

Two-Pointer Technique

Find the middle node of a linked list in a single traversal without counting the total length beforehand.

💡 Reveal Tortoise & Hare Technique & C Solution

Strategy: Maintain a slow pointer moving 1 step per turn, and a fast pointer moving 2 steps per turn. When fast reaches the end (NULL or fast->next == NULL), slow is guaranteed to be at the exact midpoint! 

struct Node* findMiddle(struct Node *head) {
    if (head == NULL) return NULL;

    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;        /* 1 step */
        fast = fast->next->next;  /* 2 steps */
    }

    return slow; /* slow is at the middle! */
}

2. Common C Pointer Pitfalls

How to diagnose and prevent segmentation faults in your lab exams

Pitfall 01
Dangling Pointers
Calling free(temp) deletes the memory block, but temp still holds the old address! Always set temp = NULL immediately after freeing.
Pitfall 02
Premature Link Break
During insertion at a position, doing prev->next = newNode before saving prev->next permanently severs the rest of the list!
Pitfall 03
Circular Infinite Loop
Checking while(temp != NULL) on a circular list will never terminate because circular lists never reach NULL. Use do { ... } while(temp != head);.
