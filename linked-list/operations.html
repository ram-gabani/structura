Linked List Operations in C

Because elements are linked by addresses rather than physical memory indices, every insertion and deletion is executed by redirecting pointer coordinates. Master the essential algorithms for inserting, deleting, and searching nodes.

1. Insert at Beginning (Prepend)

Adding a new first node in constant time

⚡ O(1) Time
Algorithmic Steps:
  1. Allocate new node newNode with malloc() and set newNode->data = val.
  2. Point newNode->next to the current head.
  3. Update head to point to newNode.
POINTER FLOW:
Step 1: newNode->next = head;  /* New node attaches to old first node */
Step 2: head = newNode;          /* HEAD moves to new node in 1 step! */
C Implementation 
struct Node* insertAtBeginning(struct Node *head, int val) {
    struct Node *newNode = (struct Node*)malloc(sizeof(struct Node));
    if (newNode == NULL) {
        printf("Memory allocation failed!\n");
        return head;
    }
    newNode->data = val;
    newNode->next = head;  /* Connect new node to current head */
    head = newNode;        /* Update head to point to new node */
    return head;           /* Return updated head pointer */
}

2. Insert at End (Append)

Traversing to the tail node and attaching the new element

🚶 O(n) Time
Algorithmic Steps:
  1. Allocate newNode and set newNode->next = NULL.
  2. Special Case: If head == NULL (list is empty), set head = newNode and return.
  3. Otherwise, use a temporary pointer temp to scan until temp->next == NULL (the tail).
  4. Set temp->next = newNode.
C Implementation 
struct Node* insertAtEnd(struct Node *head, int val) {
    struct Node *newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->data = val;
    newNode->next = NULL;

    /* Empty list edge case */
    if (head == NULL) {
        return newNode;
    }

    struct Node *temp = head;
    /* Traverse until we reach the last node */
    while (temp->next != NULL) {
        temp = temp->next;
    }

    temp->next = newNode; /* Link last node to new node */
    return head;
}

3. Insert at Specific Position

Rewiring pointers in the middle of an existing chain

🚶 O(pos) Time
To insert at position pos (1-indexed):
  1. If pos == 1, call insertAtBeginning().
  2. Traverse pos - 2 steps to reach the node immediately prior to the insertion target.
  3. Link newNode->next = temp->next (Crucial! Connect downstream first to prevent losing the chain).
  4. Link temp->next = newNode.
C Implementation 
struct Node* insertAtPosition(struct Node *head, int val, int pos) {
    if (pos < 1) {
        printf("Invalid position!\n");
        return head;
    }
    if (pos == 1) {
        return insertAtBeginning(head, val);
    }

    struct Node *temp = head;
    /* Move to the (pos - 1)th node */
    for (int i = 1; i < pos - 1 && temp != NULL; i++) {
        temp = temp->next;
    }

    if (temp == NULL) {
        printf("Position out of bounds!\n");
        return head;
    }

    struct Node *newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->data = val;
    newNode->next = temp->next; /* Step 1: Hook to subsequent node */
    temp->next = newNode;       /* Step 2: Hook previous node to new node */

    return head;
}

4. Deletion Algorithms: Beginning, End & Position

Safely freeing memory without causing dangling pointers

A. Delete From Beginning

Save head in temp, advance head = head->next, then call free(temp). 

struct Node* deleteBeginning(struct Node *head) {
    if (head == NULL) return NULL;
    struct Node *temp = head;
    head = head->next;
    free(temp); /* Deallocate memory */
    return head;
}
⚡ O(1) Time

B. Delete From End

Traverse to the second-to-last node where temp->next->next == NULL. Free the tail and set temp->next = NULL. 

struct Node* deleteEnd(struct Node *head) {
    if (head == NULL) return NULL;
    if (head->next == NULL) {
        free(head);
        return NULL;
    }
    struct Node *temp = head;
    while (temp->next->next != NULL) {
        temp = temp->next;
    }
    free(temp->next);
    temp->next = NULL;
    return head;
}
🚶 O(n) Time

5. Searching in a Linked List

Iterative pointer traversal to locate a target value

🚶 O(n) Time

Unlike sorted arrays which support O(log n) Binary Search, a linked list cannot jump directly to the middle node because there is no direct arithmetic index. Hence, searching is always linear (O(n)).

C Search Function 
int search(struct Node *head, int target) {
    struct Node *temp = head;
    int position = 1;

    while (temp != NULL) {
        if (temp->data == target) {
            return position; /* Found! Return 1-based index */
        }
        temp = temp->next;
        position++;
    }

    return -1; /* Not found in list */
}

Insert at Beginning ⚡ O(1) O(1) HEAD pointer is rewired directly in 2 constant steps
Insert at End 🚶 O(n) O(1) Must traverse from HEAD to the tail node (O(1) if tail pointer maintained)
Insert at Position 🚶 O(pos) O(1) Requires stepping through pos nodes to rewire pointer
