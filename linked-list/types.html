The Four Types of Linked Lists

Depending on whether pointer connections move forward only, backward as well, or loop around in a perpetual cycle, linked lists take four distinct forms. Each variation offers distinct algorithmic advantages.

1. Singly Linked List (Unidirectional)

The simplest linear pointer chain: forward navigation only

Key Characteristics:

  • Pointer Direction: Strictly forward (left-to-right). Cannot step backward to a previous node.
  • Termination: The last node's next is explicitly set to NULL.
  • Memory Overhead: Minimal: only one pointer field (struct Node *next) per node.
  • Ideal Use: Implementing Stacks, simple queues, and symbol tables where only forward scanning is required.
C Struct Definition 
struct Node {
    int data;           /* 4 bytes */
    struct Node *next;  /* 8 bytes pointer */
};

Key Characteristics:

  • Bidirectional Movement: You can step both forward (curr->next) and backward (curr->prev).
  • Instant Node Deletion: If you hold a pointer to node curr, you can delete it in O(1) time without having to traverse from HEAD to find its predecessor!
  • Overhead: Requires 2 pointer addresses per node (typically +16 bytes on 64-bit systems).
  • Ideal Use: Browser History (Back / Forward buttons), Music Player playlists, and Undo/Redo buffers.
C Struct Definition 
struct DNode {
    int data;
    struct DNode *prev; /* Back pointer */
    struct DNode *next; /* Forward pointer */
};

Key Characteristics:

  • Zero NULL Pointers: No node ever contains NULL! The loop condition is temp->next != head.
  • Full Cycle Reachability: You can start traversal from any node and eventually reach every other node.
  • Caution — Infinite Loops: A standard while(temp != NULL) will run in an infinite loop forever!
  • Ideal Use: Operating System Round-Robin CPU scheduling, multiplayer turn-taking games, and looping audio tracks.
Loop Traversal Condition 
/* Correct Circular Traversal in C */
struct Node *temp = head;
if (head != NULL) {
    do {
        printf("%d ", temp->data);
        temp = temp->next;
    } while (temp != head);
}
