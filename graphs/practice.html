Problem 01

Detect a Cycle in an Undirected Graph using DFS

O(V + E) Time

Write a C function using Depth-First Search to detect if an undirected graph contains any cycles. When visiting an adjacent neighbor that is already marked as visited, how do you distinguish between a genuine cycle and simply looking back at the immediate parent vertex?

Hint: Pass a parent parameter into your DFS function. If neighbor v is already visited AND v != parent, you have found a back-edge and a cycle exists!
View Complete C Solution ↓ 
#include <stdio.h>
#include <stdbool.h>
#define V 5

bool isCyclicDFS(int adj[V][V], int v, bool visited[], int parent) {
    visited[v] = true;

    for (int neighbor = 0; neighbor < V; neighbor++) {
        if (adj[v][neighbor] == 1) {
            // If neighbor not visited, recurse
            if (!visited[neighbor]) {
                if (isCyclicDFS(adj, neighbor, visited, v))
                    return true;
            }
            // If visited and not parent of current vertex, cycle found!
            else if (neighbor != parent) {
                return true;
            }
        }
    }
    return false;
}

bool hasCycle(int adj[V][V]) {
    bool visited[V] = {false};
    // Check all components in case graph is disconnected
    for (int i = 0; i < V; i++) {
        if (!visited[i]) {
            if (isCyclicDFS(adj, i, visited, -1))
                return true;
        }
    }
    return false;
}
Problem 02

Check if an Undirected Graph is Connected

O(V + E) Time

Write a C function to determine whether an undirected graph is connected. A graph is connected if every vertex is reachable from vertex 0.

Hint: Run BFS or DFS starting from vertex 0. Afterwards, scan the visited array. If any vertex remains unvisited (0), the graph is disconnected!
View Complete C Solution ↓ 
#include <stdio.h>
#include <stdbool.h>
#define V 4

void bfsExplore(int adj[V][V], int start, bool visited[]) {
    int queue[V];
    int front = 0, rear = 0;

    visited[start] = true;
    queue[rear++] = start;

    while (front < rear) {
        int u = queue[front++];
        for (int v = 0; v < V; v++) {
            if (adj[u][v] == 1 && !visited[v]) {
                visited[v] = true;
                queue[rear++] = v;
            }
        }
    }
}

bool isConnected(int adj[V][V]) {
    bool visited[V] = {false};
    bfsExplore(adj, 0, visited);

    // If any vertex was not reached from 0, graph is disconnected
    for (int i = 0; i < V; i++) {
        if (!visited[i]) return false;
    }
    return true;
}
Problem 03

Calculate Degree of Vertices from an Adjacency Matrix

O(V²) Time

Write a concise C function that prints the degree of every vertex in an undirected graph given its Adjacency Matrix.

Hint: In an undirected adjacency matrix, the degree of vertex i is simply the sum of all 1s in row i!
View Complete C Solution ↓ 
#include <stdio.h>
#define V 4

void printDegrees(int adj[V][V]) {
    for (int i = 0; i < V; i++) {
        int degree = 0;
        for (int j = 0; j < V; j++) {
            if (adj[i][j] == 1) degree++;
        }
        printf("Vertex %d: Degree = %d\n", i, degree);
    }
}

2. Common Graph Programming Pitfalls in C

Bugs that crash student programs in lab examinations

Pitfall 01
Omitting Visited Array
Calling DFS without checking visited[neighbor] triggers infinite recursive stack overflow because cycles bounce back and forth forever between vertices!
Pitfall 02
Ignoring Disconnected Graphs
Starting BFS only at vertex 0 fails to discover vertices in disconnected components. Always use a loop over all 0 to V-1 for full graph coverage.
Pitfall 03
One-Way Undirected Edge
Setting only adj[u][v] = 1 without setting adj[v][u] = 1 turns an undirected graph into a directed graph, producing wrong traversal paths.
