Graph Traversals: BFS & DFS

Unlike linear arrays or trees that have an obvious beginning and end, a graph can have cycles and multiple interconnected paths. To visit every vertex exactly once without getting trapped in infinite loops, we maintain a Visited Array and use either Breadth-First Search (BFS) or Depth-First Search (DFS).

The Crucial Component: The Visited Array

Why graph traversal is fundamentally different from tree traversal

In a tree, there is only one unique path to each node, and cycles are impossible. But in a graph with cycles (e.g. A → B → C → A), traversing neighbors blindly will loop indefinitely!

int visited[V] = {0}; // 0 = unvisited, 1 = visited

Before pushing a neighbor to a queue or making a recursive call, we check if (!visited[neighbor]). Once explored, we mark visited[neighbor] = 1. This guarantees that each vertex is processed exactly once!

1. Breadth-First Search (BFS — Queue Based)

Level-by-level concentric expansion using a First-In, First-Out Queue

⚡ O(V + E) Time

BFS Algorithm Strategy: Like ripples on a pond, BFS explores all direct 1-hop neighbors of the starting node first, then all 2-hop neighbors, then 3-hop neighbors. Because arrivals must be serviced in order of discovery, BFS requires a FIFO Queue.

Step 1: Enqueue starting vertex S and mark visited[S] = 1.
Step 2: While queue is not empty, dequeue front vertex curr.
Step 3: Print/process curr.
Step 4: For each adjacent neighbor v of curr: if !visited[v], mark visited[v] = 1 and enqueue v.
Step 5: Repeat until queue is empty. 
#include <stdio.h>
#include <stdlib.h>
#define MAX_V 6

// BFS using an Adjacency Matrix and Array-based Queue
void BFS(int adj[MAX_V][MAX_V], int startVertex, int numVertices) {
    int visited[MAX_V] = {0};
    int queue[MAX_V];
    int front = 0, rear = 0;

    // Enqueue start vertex and mark visited
    visited[startVertex] = 1;
    queue[rear++] = startVertex;

    printf("BFS Traversal Order: ");

    while (front < rear) {
        // Dequeue current vertex
        int curr = queue[front++];
        printf("%d ", curr);

        // Inspect all adjacent neighbors
        for (int neighbor = 0; neighbor < numVertices; neighbor++) {
            if (adj[curr][neighbor] == 1 && !visited[neighbor]) {
                visited[neighbor] = 1;
                queue[rear++] = neighbor; // Enqueue neighbor
            }
        }
    }
    printf("\n");
}
Primary Use Cases of BFS: Shortest path in an unweighted graph (e.g. minimum degree of separation on LinkedIn), GPS shortest hop routing, and web crawling.

2. Depth-First Search (DFS — Recursion / Stack)

Deep branch dive until a dead end, then backtrack using the function call stack

⚡ O(V + E) Time

DFS Algorithm Strategy: DFS behaves like exploring a maze. It charges down a chosen path as deeply as possible until it hits a vertex with no unvisited neighbors (a dead end). It then backtracks to the previous vertex and explores alternative unexplored branches.

Step 1: Mark current vertex curr as visited and print it.
Step 2: For each neighbor v of curr: if !visited[v], recursively call DFS(v).
Step 3: Backtrack automatically when all neighbors of curr are visited. 
#include <stdio.h>
#define MAX_V 6

// Recursive Depth-First Search function
void DFSUtil(int adj[MAX_V][MAX_V], int curr, int visited[MAX_V], int numVertices) {
    // Mark current vertex as visited and process it
    visited[curr] = 1;
    printf("%d ", curr);

    // Recursively visit all unvisited adjacent neighbors
    for (int neighbor = 0; neighbor < numVertices; neighbor++) {
        if (adj[curr][neighbor] == 1 && !visited[neighbor]) {
            DFSUtil(adj, neighbor, visited, numVertices);
        }
    }
}

// Wrapper function to initialize visited array
void DFS(int adj[MAX_V][MAX_V], int startVertex, int numVertices) {
    int visited[MAX_V] = {0};
    printf("DFS Traversal Order: ");
    DFSUtil(adj, startVertex, visited, numVertices);
    printf("\n");
}
Primary Use Cases of DFS: Cycle detection in graphs, Topological Sorting for compile dependencies, maze solving, and finding strongly connected components.

BFS vs DFS: Algorithm Comparison

Key architectural differences between breadth and depth approaches

Feature / Metric Breadth-First Search (BFS) Depth-First Search (DFS)
Auxiliary Data Structure FIFO Queue LIFO Stack / Call Stack
Exploration Style Level-by-level (shallow, wide ripples) Branch-by-branch (deep dive, then backtrack)
Time Complexity O(V + E) (using adjacency list) O(V + E) (using adjacency list)
Auxiliary Space O(V) to hold queue vertices O(V) worst case for recursion call stack
Shortest Path Guarantee Yes (for unweighted graphs) No (finds any arbitrary path)
Memory Behavior Can consume heavy RAM in dense wide networks Lean memory if tree/graph is shallow
