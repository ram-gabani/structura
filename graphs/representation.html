Graph Representation in C Memory

How does a computer represent a graph of vertices and edges in RAM? Because graphs are non-linear, we cannot simply use a single 1D array. Computer scientists use two primary techniques: the Adjacency Matrix (a 2D lookup grid) and the Adjacency List (an array of dynamic pointer chains).

Our Benchmark 4-Vertex Graph

We will represent this exact undirected graph using both methods

Vertices: V = { 0, 1, 2, 3 } (|V| = 4)
Edges: (0,1), (0,2), (0,3), (1,3), (2,3) (|E| = 5)
Note: Edge (0,3) crosses diagonally across the center.

1. Adjacency Matrix (2D Array)

A V × V boolean grid where adj[u][v] = 1 indicates an edge

⚡ O(1) Edge Lookup

In an Adjacency Matrix, we declare a 2D array int adj[V][V]. If an edge exists between vertex i and vertex j, we store adj[i][j] = 1. If no edge exists, we store 0. For undirected graphs, the matrix is always symmetric across the main diagonal (i.e. adj[i][j] == adj[j][i]).

adj[i][j] Vertex 0 Vertex 1 Vertex 2 Vertex 3
Vertex 0 0 1 1 1
Vertex 1 1 0 0 1
Vertex 2 1 0 0 1
Vertex 3 1 1 1 0 
#include <stdio.h>
#define V 4

// Initialize all slots to 0 (no edges)
void initMatrix(int adj[V][V]) {
    for (int i = 0; i < V; i++)
        for (int j = 0; j < V; j++)
            adj[i][j] = 0;
}

// Add an undirected edge (u <-> v)
void addEdgeMatrix(int adj[V][V], int u, int v) {
    adj[u][v] = 1;
    adj[v][u] = 1; // Symmetric for undirected graph
}

// Check if edge exists in O(1) time
int hasEdge(int adj[V][V], int u, int v) {
    return adj[u][v] == 1;
}

void printMatrix(int adj[V][V]) {
    printf("Adjacency Matrix:\n");
    for (int i = 0; i < V; i++) {
        for (int j = 0; j < V; j++) {
            printf("%d ", adj[i][j]);
        }
        printf("\n");
    }
}
Advantages: Instant O(1) edge lookup adj[u][v]. Adding or removing an edge takes O(1) time. Extremely simple to code in C.
Limitations: Requires O(V²) physical RAM regardless of how few edges exist! For 100,000 vertices, a matrix requires 40 Gigabytes of RAM even if there are only 5 edges.

2. Adjacency List (Array of Linked Lists)

An array of head pointers where each vertex points to a linked list of its neighbors

🚀 O(V + E) Space Optimal

In an Adjacency List, we declare an array of linked list head pointers struct Node* adjList[V]. Each slot i stores the memory address of the first neighbor of vertex i. If vertex i has 3 neighbors, its linked list contains exactly 3 nodes.

adjList[0] → [ 1 | * ] → [ 2 | * ] → [ 3 | NULL ]
adjList[1] → [ 0 | * ] → [ 3 | NULL ]
adjList[2] → [ 0 | * ] → [ 3 | NULL ]
adjList[3] → [ 0 | * ] → [ 1 | * ] → [ 2 | NULL ]
#include <stdio.h>
#include <stdlib.h>

// Node in neighbor linked list
struct Node {
    int dest;
    struct Node* next;
};

// Graph structure: array of head pointers
struct Graph {
    int numVertices;
    struct Node** adjList;
};

struct Node* createNode(int v) {
    struct Node* newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->dest = v;
    newNode->next = NULL;
    return newNode;
}

struct Graph* createGraph(int vertices) {
    struct Graph* graph = (struct Graph*)malloc(sizeof(struct Graph));
    graph->numVertices = vertices;
    graph->adjList = (struct Node**)malloc(vertices * sizeof(struct Node*));
    for (int i = 0; i < vertices; i++)
        graph->adjList[i] = NULL;
    return graph;
}

// Prepend neighbor node to head of list in O(1) time
void addEdgeList(struct Graph* graph, int src, int dest) {
    // Add edge from src to dest
    struct Node* newNode = createNode(dest);
    newNode->next = graph->adjList[src];
    graph->adjList[src] = newNode;

    // For undirected graph, add reverse edge dest to src
    newNode = createNode(src);
    newNode->next = graph->adjList[dest];
    graph->adjList[dest] = newNode;
}
Advantages: Highly space-efficient: consumes only O(V + E) bytes. Traversing all neighbors of vertex u takes O(degree(u)) time instead of scanning V empty slots.
Limitations: Checking if edge (u, v) exists is not O(1); it requires traversing vertex u's linked list in O(deg(u)) time.

Matrix vs List: Decision Matrix

Side-by-side technical trade-offs for examinations

Feature / Metric Adjacency Matrix Adjacency List Architectural Rationale
RAM Memory Space O(V²) ⚡ O(V + E) Matrix allocates space for every possible edge; List stores only existing edges
Check if Edge (u,v) Exists ⚡ O(1) O(degree(u)) Matrix directly indexes adj[u][v]; List must traverse pointer chain
Find All Neighbors of Vertex u O(V) ⚡ O(degree(u)) Matrix must iterate through all V columns; List visits only adjacent neighbor nodes
Add a New Edge (u, v) O(1) O(1) Matrix updates cell; List prepends new node to head of adjList[u]
Best Suited For Dense Graphs (|E| ≈ |V|²) Sparse Graphs (|E| ≪ |V|²) Almost all real-world networks (roads, web, social) are sparse graphs
