What is a Graph?

Arrays and linked lists connect elements sequentially in a single line. Trees organize data strictly in a one-way hierarchical parent-child structure with zero cycles. But how do we model a flight network connecting 50 global cities, or a social network where friendships criss-cross in every direction?

A Graph is the most versatile non-linear data structure in computer science. Mathematically defined as G = (V, E), it consists of a non-empty set of Vertices (Nodes) interconnected by a set of Edges (Arcs / Links) that can model arbitrary cyclic networks without any hierarchy!

Vertices (V)
Data Entities
Individual objects, cities, routers, or people represented as labeled nodes in the network.
Edges (E)
Connections
Pairwise relations or channels connecting pairs of vertices: e = (u, v).
Arbitrary Topology
No Root Node
Unlike trees, graphs have no designated root. Vertices may form closed loops and cycles.
Path & Reachability
Route Finding
A sequence of connected edges that allows traversing from vertex u to vertex v.

Essential Graph Terminology & Definitions

Core vocabulary required for university examinations and technical interviews

1. Vertex (Node) & Edge (Arc)

A Vertex is a primary data item (e.g. computer, airport, intersection). An Edge is an unordered or ordered pair connecting two vertices (u, v). Two vertices connected directly by an edge are called Adjacent or Neighbors.

2. Degree of a Vertex (Handshaking Theorem)

In an undirected graph, the Degree of vertex v is the number of edges incident to it.
Academic Handshaking Theorem: The sum of degrees of all vertices equals twice the total number of edges: ∑ deg(v) = 2 × |E|.

3. Path, Simple Path & Cycle

A Path is a sequence of consecutive vertices connected by edges. A path is Simple if no vertex is visited more than once. A Cycle is a closed path where the starting vertex and ending vertex are identical (e.g., A → B → C → A). An Acyclic Graph contains zero cycles.

4. Connected vs Disconnected Graphs

An undirected graph is Connected if there exists at least one valid path between every pair of vertices. If some vertices are isolated with no path connecting them to the rest, the graph is Disconnected and consists of separate Connected Components.

Major Graph Classifications

How edge properties alter the topology and algorithm choice

Directionality

Undirected vs Directed (Digraph)

Undirected Graph: Edges are two-way bidirectional highways: (u, v) == (v, u). If A connects to B, you can freely travel from B to A.

Directed Graph (Digraph): Edges have one-way direction arrows: ⟨u, v⟩ ≠ ⟨v, u⟩. Vertex v has an In-Degree (incoming arrows) and an Out-Degree (outgoing arrows).

Edge Weights

Weighted vs Unweighted Graphs

Unweighted Graph: Every edge simply represents existence of a link (all edge costs equal 1). Common in social networks (friend / not friend).

Weighted Graph: Every edge carries a numerical cost, distance, latency, or toll. Essential for Google Maps navigation (Dijkstra's shortest path) and network packet routing.

Real-World Graph Applications

Why computer scientists model modern infrastructure using graphs

Road Networks
GPS & Maps
Intersections are vertices, roads are edges, and travel time in minutes is the edge weight. One-way streets form a directed graph!
Social Graphs
People & Followers
Facebook friendships are bidirectional (undirected graph). Twitter/Instagram following is one-way (directed graph).
The Internet
Web & Routing
Webpages are vertices; hyperlinked URLs are directed edges (Google PageRank). Routers communicate packets over weighted fiber lines.
