The Four Types of Queues

Standard Linear Queues suffer from a severe architectural flaw: False Overflow. Explore how Circular Queues solve memory wastage through ring buffers, how Deques permit two-ended access, and how Priority Queues serve high-urgency items first.

1. Linear Queue & The False Overflow Problem

Why standard array queues waste precious computer RAM

Limitation

In a Linear Queue implemented on an array of size 5:

RAM SLOTS [0] TO [4]:
Slot [0] Vacated
Slot [1] Vacated
FRONT [2] 30
Slot [3] 40
REAR [4] 50
⚠️ False Overflow State: REAR is at index 4 (MAX - 1). If you attempt to enqueue another element, rear == MAX - 1 reports Queue Overflow! Yet Slots 0 and 1 are completely EMPTY!

Because both front and rear march monotonically forward, the queue "drifts" rightward through RAM, abandoning vacated slots behind it. Shifting all elements left after every dequeue would take O(n) time, destroying efficiency.

2. Circular Queue: The Ring Buffer Solution

Reusing vacated front slots using modulo arithmetic

Optimal

A Circular Queue conceptually folds the straight array into a continuous circle. When rear reaches the final index MAX - 1, it does not stop; it wraps around back to index 0 if front slots have been vacated!

📐 Modulo Wrap-Around Formulas:

• Enqueue Pointer Advance: rear = (rear + 1) % MAX
• Dequeue Pointer Advance: front = (front + 1) % MAX
• Circular Full Condition: (rear + 1) % MAX == front
Circular Enqueue in C 
void enqueue(struct CircularQueue *q, int val) {
    /* Full condition: next rear would hit front */
    if ((q->rear + 1) % MAX == q->front) {
        printf("Circular Queue Overflow!\n");
        return;
    }
    if (q->front == -1) { /* First element */
        q->front = 0;
    }
    q->rear = (q->rear + 1) % MAX;
    q->arr[q->rear] = val;
}

3. Deque & Priority Queue

Specialized variations for advanced system architectures

A. Double-Ended Queue (Deque)

A general linear list where insertions and deletions are permitted at both ends (both Front and Rear).

  • Input-Restricted Deque: Insertion permitted only at Rear; deletions allowed at both Front & Rear.
  • Output-Restricted Deque: Deletion permitted only at Front; insertions allowed at both Front & Rear.
  • Use Case: Web crawler URL caches, undo-redo histories, and A-Steal work scheduling algorithms.

B. Priority Queue

Each element has an associated priority value. Elements with higher priority are dequeued before lower-priority elements.

  • Ascending Priority: Lowest numeric key served first (e.g. Dijkstra's shortest path).
  • Descending Priority: Highest numeric key served first (e.g. VIP customer queue).
  • Use Case: Hospital emergency room triage, CPU process priority scheduling, Dijkstra's algorithm.
