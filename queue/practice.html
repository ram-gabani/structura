Challenge 1: Implement a Queue using Two Stacks

Classic Interview Problem

How can you construct a FIFO Queue using only two standard LIFO Stacks (stack1 and stack2)?

💡 Reveal 2-Stack Transfer Technique & C Solution

Strategy: stack1 handles arrivals (enqueue always pushes onto stack1). When dequeue is called, if stack2 is empty, pop all elements from stack1 and push them into stack2 (reversing their order to FIFO!). Then pop from stack2. 

/* Enqueue: Always push onto s1 */
void myQueueEnqueue(struct Stack *s1, int x) {
    push(s1, x);
}

/* Dequeue: Pop from s2; transfer if s2 empty */
int myQueueDequeue(struct Stack *s1, struct Stack *s2) {
    if (isEmpty(s2)) {
        while (!isEmpty(s1)) {
            push(s2, pop(s1)); /* Reverse order */
        }
    }
    if (isEmpty(s2)) {
        printf("Queue is Empty!\n");
        return -1;
    }
    return pop(s2);
}

Challenge 2: Generate Binary Numbers 1 to N using Queue

BFS Generation

Print the binary representation of all numbers from 1 to N (e.g. 1 → 1, 10, 11, 100, 101, ...) in \(O(N)\) time using a string queue.

💡 Reveal String Append Queue Technique

Strategy: Enqueue "1". For each turn, dequeue current string s, print it, and enqueue s + "0" and s + "1". This executes an elegant level-order Breadth-First tree generation of binary digits!

2. Common Queue Pitfalls in C

Avoid these 3 frequent mistakes in practical tests

Pitfall 01
False Overflow in Linear Queue
Assuming rear == MAX - 1 means the queue is full even after multiple dequeues. In a linear queue, front slots are wasted!
Pitfall 02
Missing Empty Reset on Last Item
When popping the very last item in a circular queue (front == rear), you must reset front = -1; rear = -1; instead of advancing via modulo!
Pitfall 03
Modulo Operator Precedence
Writing rear + 1 % MAX calculates rear + (1 % MAX)! Always use parentheses: (rear + 1) % MAX.
